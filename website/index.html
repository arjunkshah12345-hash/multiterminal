Install in under a minute

Requires macOS 12+ and the Swift toolchain.

# Build & run (first run fetches SwiftTerm, then it's instant)
git clone https://github.com/arjunkshah12345-hash/multiterminal.git
cd multiterminal
swift run

# Or build a double-clickable .app with the icon
sh tools/build_app.sh release
open Multiterminal.app
⌘T new terminal ⌘N new project ⌘O open folder as project ⌘, settings ⌘W close terminal

FAQ

Is it a real terminal, or just a fake UI? Real. Every pane is a genuine PTY running your login shell — zsh, bash, fish, whatever you use. Commands, history, and tools all behave exactly as expected.
Does it reopen my work after I quit? Yes. On relaunch, Multiterminal restores your projects, their folders, and how many panes each had. Shell history lives in your normal history file, so it's there too.
Can I resize or reorganize panes? Yes — drag any divider to resize, or right-click a pane header to move it left/right or into another project.
Is my data local? Fully local. No account, no cloud, no telemetry. Your projects are stored in your user defaults and folders stay exactly where you put them.
How is it so fast and small? Native Swift + AppKit using the SwiftTerm terminal engine. No Electron, no browser, no webview — a single lightweight native binary.
