03 · how it works

root. compose. return.

The app stays small because the model stays clear: projects own folders, panes own real shells, and the layout stays editable while you work.

01

Open a project

Choose a folder and it becomes a project. New panes start there, so your working directory is always obvious.

02

Run a real shell

zsh, bash, or fish through a genuine PTY. Your aliases, environment, tooling, and history stay intact.

03

Compose the grid

Choose auto, stack, row, grid, or 2 + 1. Drag the quiet center gutters when one pane needs more room.

04

Build against it

The local MCP bridge exposes projects, sessions, output, focus, and safe editing tools so other apps can work with the same live workspace.

05

Name & theme

Rename any pane by double-clicking its header or right-clicking → Rename…. Switch themes live — Forest, Ink, Slate, Sand, or Light — and every shell, scrollback, and layout keeps running.

04 · install

put it on your mac

No account, no cloud setup, no App Store. Download the app and drag it into Applications — or build it from source. macOS 12+, Apple Silicon & Intel.

Download for Mac

~3 MB · free · no Apple Developer ID required

  1. Open Multiterminal.dmg and drag Multiterminal into Applications.
  2. In Applications, right-click Multiterminal → Open the first time. This clears Gatekeeper once (the app isn’t notarized).
  3. Launch it any time from Launchpad or Spotlight.

Power-user one-liner — copy the app and clear quarantine from the terminal:

# mount the dmg, install, clear Gatekeeper quarantine
$ cp -R /Volumes/Multiterminal/Multiterminal.app /Applications && \
  hdiutil detach /Volumes/Multiterminal && \
  xattr -dr com.apple.quarantine /Applications/Multiterminal.app
# clone and run
$ git clone https://github.com/arjunkshah12345-hash/multiterminal.git
$ cd multiterminal
$ swift run

shortcut surface default meaning
⌘T terminal new open a pane in the current project
⌘O project folder open a folder as a project
⌘⇧P quick view floating jump across every session
⌘W terminal close close the focused pane without moving focus
⌘K terminal clear clear the focused pane's screen
⌘] focus next move keyboard focus to the next pane
⌘[ focus prev move keyboard focus to the previous pane
⌘, settings live change theme, appearance, and type size
double-click pane header rename the focused pane
