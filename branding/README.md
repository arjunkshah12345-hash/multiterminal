# Multiterminal brand

Multiterminal stays Multiterminal. The identity is built around one idea: many live
terminals, composed into one calm surface.

## Mark

The mark combines a pane frame, a terminal prompt, and a cursor. The quiet internal
cross suggests multiple panes without turning into a generic grid icon.

- Primary mark: [`mark.svg`](mark.svg)
- App icon source: [`../tools/make_icon.swift`](../tools/make_icon.swift)
- Web share card: [`../website/assets/brand-card.svg`](../website/assets/brand-card.svg)

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#060A08` | Native black canvas, terminal surfaces |
| Forest | `#101A16` | Background start, quiet chrome |
| Deep green | `#1C4A40` | Background depth |
| Signal mint | `#78CDBE` | Focus, cursor, primary action |
| Terminal white | `#EEF4E4` | Type, contrast, and controls |

Keep the mark quiet at rest. Use the signal mint for focus and action, not for
every label or surface.
